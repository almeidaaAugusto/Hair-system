# Implement user story

## Processo obrigatório

1. Leia o AGENTS.md aplicável.
2. Leia os documentos relacionados em docs/.
3. Inspecione o código existente antes de propor novas abstrações.
4. Converta a solicitação em:
   - comportamento esperado;
   - critérios de aceitação;
   - regras de negócio afetadas;
   - casos de erro;
   - testes necessários.
5. Identifique dúvidas que impedem a implementação.
6. Quando a dúvida não impedir o trabalho, registre uma hipótese em
   docs/product/open-questions.md e prossiga com a opção mais simples.
7. Implemente a menor mudança completa possível.
8. Não misture refatorações não relacionadas.
9. Adicione testes.
10. Execute os quality gates do AGENTS.md.
11. Revise o diff completo.

## Entrega

Apresente:

- comportamento implementado;
- arquivos principais alterados;
- testes executados;
- hipóteses utilizadas;
- riscos ou pendências reais.

Nunca informe que a tarefa está concluída quando testes estiverem falhando.
